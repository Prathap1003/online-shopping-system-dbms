# 🛒 Online Shopping System

A Database Management System (DBMS) project designed to manage and organize online shopping information such as customers, sellers, product categories, products, carts, orders, reviews, and returns.

---

## 📌 Project Overview

The **Online Shopping System** provides a structured relational database for managing the core activities of an online shopping platform and maintaining relationships between the different entities.

The project demonstrates database design, table creation, data manipulation, constraints, and SQL queries using **PostgreSQL**.

---

## 🎯 Objectives

- Design a structured relational database for an online shopping system.
- Create tables using appropriate primary keys and foreign keys.
- Apply NOT NULL, UNIQUE, and CHECK constraints to maintain data integrity.
- Insert and manage sample shopping data.
- Perform CRUD operations.
- Perform SQL JOIN operations.
- Use aggregate functions, GROUP BY / HAVING, and subqueries for data analysis.
- Demonstrate views, set operations, DCL, and TCL.
- Design and represent the database using an ER diagram and relational schema.

---

## 🗄️ Database Entities

The database consists of the following major entities:

- **Customer**
- **Seller**
- **Category**
- **Product**
- **Cart**
- **Orders**
- **Review**
- **Return**

These entities are related using primary keys and foreign keys to maintain data consistency and integrity.

## 📄 SQL Files

### ddl.sql

Contains the Data Definition Language (DDL) statements used to create:

- Database tables
- Primary keys
- Foreign keys
- Constraints (NOT NULL, UNIQUE, CHECK)

### dml.sql

Contains the Data Manipulation Language (DML) statements used to insert sample data into all eight tables.

### queries.sql

Contains SQL queries demonstrating:

- SELECT operations (basic, filtered, LIKE)
- INSERT, UPDATE, and DELETE operations
- JOIN operations
- Aggregate functions, GROUP BY, and HAVING
- Subqueries
- Views and set operations (UNION)
- DCL (GRANT / REVOKE) and TCL (SAVEPOINT / ROLLBACK)

## ▶️ How to Run

1. Open **dbfiddle.dev** and select **PostgreSQL**, or use any PostgreSQL client.
2. Run `sql/ddl.sql` to create the tables.
3. Run `sql/dml.sql` to insert the sample data.
4. Run the queries from `sql/queries.sql` to test the operations.
